# Locked decisions

These decisions are resolved. Do not revisit them.

**0-c.Q1 — `Shell.faces` stays a defining field.** A shell is defined by its faces
plus senses, so `faces: Vec<FaceId>` remains on `Shell`. Only the shell's *edges and
vertices* are convenience and move to side-tables. The golden dump's top-down defining
traversal depends on this.

**0-c.Q2 — relative tolerance form (option A) plus angular handling.**
- `fuzzy_eq(a, b, ref_scale, tol) = |a - b| <= tol.eps_rel * max(ref_scale, tol.abs_floor)`.
  The floor is on the *scale factor*: `abs_floor` is a **minimum reference scale** (a
  denormal/underflow guard), not a minimum snap distance. Document that clearly —
  the effective minimum comparison distance is `eps_rel * abs_floor`.
- Defaults: `eps_rel` ~ 1e-10 (tune if a concrete case demands it), `abs_floor` ~ 1e-12.
- Single `eps_rel` covers positions and orientations.
- **Orientation/normal comparisons** use the well-conditioned angle
  `atan2(|u × v|, u · v)` (range `[0, π]`) with `ref_scale = 1.0`, i.e. an angular
  threshold of exactly `eps_rel`. Do **not** compute the angle via `acos(u · v)` — it is
  ill-conditioned near alignment. Compare unit normals only; near-zero-length normals
  are a degeneracy to handle explicitly, not via tolerance. Do **not** add a separate
  angular floor or angular epsilon for now.

**0-c.Q3 — minimal, mechanical field-access migration.** See "Scope" below.

**0-c.Q4 — compiler entry points return `SolidSetId`.** `compile_primitive` and
`compile_csg_node` return a `SolidSetId` (not a bare `SolidId`), and each compiled
node pushes exactly one `SolidSet` into the `solidsets` arena holding the solid(s) it
produces (one for a primitive), with `source_csg_id` taken from the node's `prov_id`.
Update all callers (`py_bindings`, `inspect`, tests). This is still schema-only: do
**not** implement multi-outer extrusion or any boolean evaluation. `inspect`'s public
signatures must not change; `dump_csg_node`/`dump_mesh_csg_node` adapt internally, and
the `BRepDump`/`MeshDump` shapes (which do not include the `SolidSet` arena) must stay
identical.

# Scope

Migrate the schema; do not change behaviour. Concretely:

1. **Rename `NodeBRep` → `SolidSet`** (and `NodeBRepId` → `SolidSetId`, the arena
   `nodes` → `solidsets`, and the accessors `push_node`/`get_node`/`get_mut_node` →
   `push_solidset`/`get_solidset`/`get_mut_solidset`). `SolidSet` keeps
   `solids: Vec<SolidId>` and `source_csg_id: u64` (provenance is identity, so it stays
   a defining field). Per 0-c.Q4, also change the compiler entry points to return
   `SolidSetId` and push one `SolidSet` per compiled node. This lands first so all
   later work uses the final vocabulary. Still **no** multi-outer extrusion and **no**
   boolean evaluation.
2. **Strip convenience fields** from the b-rep structs and add `Context` side-tables:
   - `Face`: drop `shell` → `Context::shell_of_face`.
   - `Shell`: drop `solid` → `Context::solid_of_shell`; **keep `faces` and `is_outer`**.
   - `Edge`: drop `coedges` → `Context::coedges_of_edge`; add
     `Context::faces_of_edge` (derived from coedges).
   - `CoEdge`: drop `face` → `Context::face_of_coedge`.
   - `Loop`: drop `face` → `Context::face_of_loop`; keep `coedges`, `is_outer`.
   - `Solid`: keep `outer`, `inners` (defining); optionally add
     `Context::solidset_of_solid` if it is genuinely needed.
   - `Vertex`: drop `tol`; keep `point`.
   - Add `Context::{edges_of_shell, vertices_of_shell, faces_of_shell?}` as needed.
     (`Shell.faces` is defining, so `faces_of_shell` may just read the field.)
3. **`Context::rebuild_indices(&mut self)`** — one method that walks defining content
   and (re)populates every side-table. Call it once after each topological-mutating
   operation. Document that side-tables may be stale *during* an op.
4. **Tolerance**: replace `KernelTolerance { pos_tol, ang_tol, param_tol }` with
   `Tolerance { eps_rel, abs_floor }` and `fuzzy_eq(...)` as in Q2. Catalogue every
   `tolerance.pos_tol` / `ang_tol` / `param_tol` call site first, then replace each
   with an explicit `ref_scale` (edge length, bbox diagonal, etc.). Do not invent a
   per-entity tolerance — that is explicitly rejected.

**"Minimal, mechanical migration" means:** for `brep_compiler.rs`, `mesher.rs`, and
`bool_ops.rs`, substitute field access with side-table lookups and nothing else. No
reordering, no "while I'm here" refactors, no touching the `#![allow(dead_code)]`
staging markers, and **preserve iteration order** — side-table builders must populate
in the same order the old convenience fields did (the mesher walks `loop.coedges`,
`shell.faces`, etc. in insertion order; a different order can shift mesh vertex
ordering and twin-stitching). If migrating these modules shows that a side-table is
awkward to use, adjust the **side-table API** (the real deliverable) — never the
algorithm.
